This guide shows how to build forms using TanStack Form with Kanpeki's [Field](/docs/components/field) component and schema validation.

## Demo

<ComponentPreview name="tanstack-form-demo" />

## Approach

TanStack Form provides headless form state management. We combine it with:

- `Field` components for layout and accessibility
- `TextField` for automatic ID wiring between label, input, description, and error
- Any [Standard Schema](https://standardschema.dev/schema#what-schema-libraries-implement-the-spec) library (Zod, Valibot, ArkType) for validation — no adapters needed
- Real-time validation feedback

## Anatomy

```tsx
<form
  onSubmit={(e) => {
    e.preventDefault();
    e.stopPropagation();
    form.handleSubmit();
  }}
>
  <form.Field
    name="email"
    children={(field) => {
      const isInvalid =
        field.state.meta.isTouched && !field.state.meta.isValid;
      return (
        <Field.Root
          render={
            <TextField
              id={field.name}
              isInvalid={isInvalid}
              name={field.name}
              onBlur={field.handleBlur}
              onChange={field.handleChange}
              value={field.state.value}
            />
          }
        >
          <Field.Label>Email</Field.Label>
          <Input placeholder="name@example.com" />
          <Field.Description>Helper text</Field.Description>
          <Field.Error errors={field.state.meta.errors} />
        </Field.Root>
      );
    }}
  />
  <Button type="submit">Submit</Button>
</form>
```

`TextField{:tsx}` is Kanpeki's React Aria behavior adapter. It automatically wires `Field.Label{:tsx}`, `Field.Description{:tsx}`, and `Field.Error{:tsx}` via `aria-labelledby{:tsx}` and `aria-describedby{:tsx}`. See the [forms architecture](/docs/forms) for more.

## Setup

### Install dependencies

```bash
npm install @tanstack/react-form zod
```

Replace `zod` with any [Standard Schema](https://standardschema.dev/schema#what-schema-libraries-implement-the-spec)-compliant library such as `valibot` or `arktype` — TanStack Form supports them all natively with no extra adapters.

### Create a schema

Define your form shape with your schema library of choice. This example uses Zod:

```tsx
import { z } from "zod";

const formSchema = z.object({
  title: z
    .string()
    .min(5, "Title must be at least 5 characters.")
    .max(32, "Title must be at most 32 characters."),
  description: z
    .string()
    .min(20, "Description must be at least 20 characters."),
});
```

### Setup the form

Use `useForm` with your schema passed to `validators`:

```tsx
import { useForm } from "@tanstack/react-form";

const form = useForm({
  defaultValues: {
    title: "",
    description: "",
  },
  validators: {
    onChange: formSchema,
  },
  onSubmit: ({ value }) => {
    console.log(value);
  },
});
```

## Validation

### Validation Modes

TanStack Form supports different validation strategies:

| Mode       | Description                              |
| ---------- | ---------------------------------------- |
| `onSubmit` | Validate on form submission              |
| `onChange` | Validate on every change                 |
| `onBlur`   | Validate when field loses focus          |
| `onMount`  | Validate immediately when field mounts   |

```tsx
const form = useForm({
  validators: {
    onSubmit: formSchema,
    onChange: formSchema,
    onBlur: formSchema,
  },
});
```

### Displaying Errors

Use `Field.Error{:tsx}` with the `errors{:tsx}` prop. It renders nothing when the array is empty, so no conditional render is needed:

```tsx
<form.Field
  name="email"
  children={(field) => {
    const isInvalid = field.state.meta.isTouched && !field.state.meta.isValid;
    return (
      <Field.Root
        render={
          <TextField
            id={field.name}
            isInvalid={isInvalid}
            name={field.name}
            onBlur={field.handleBlur}
            onChange={field.handleChange}
            value={field.state.value}
          />
        }
      >
        <Field.Label>Email</Field.Label>
        <Input type="email" />
        <Field.Error errors={field.state.meta.errors} />
      </Field.Root>
    );
  }}
/>
```

### Select

<ComponentPreview name="tanstack-form-select-demo" />

Pass `Select.Root{:tsx}` as the `render{:tsx}` prop on `Field.Root{:tsx}`. Use `selectedKey{:tsx}` and `onSelectionChange{:tsx}` for TanStack Form wiring.

```tsx
<form.Field
  name="country"
  children={(field) => {
    const isInvalid = field.state.meta.isTouched && !field.state.meta.isValid;
    return (
      <Field.Root
        render={
          <Select.Root
            isInvalid={isInvalid}
            name={field.name}
            onSelectionChange={(key) => field.handleChange(key as string)}
            placeholder="Select a country"
            selectedKey={field.state.value || null}
          />
        }
      >
        <Field.Label>Country</Field.Label>
        <Select.Trigger>
          <Select.Value />
        </Select.Trigger>
        <Popover.Content>
          <Listbox.Root>
            <Listbox.Item id="us">United States</Listbox.Item>
            <Listbox.Item id="uk">United Kingdom</Listbox.Item>
            <Listbox.Item id="ca">Canada</Listbox.Item>
          </Listbox.Root>
        </Popover.Content>
        <Field.Error errors={field.state.meta.errors} />
      </Field.Root>
    );
  }}
/>
```

### Checkbox

<ComponentPreview name="tanstack-form-checkbox-demo" />

For checkbox groups, use `mode="array"{:tsx}` and pass `Checkbox.Provider{:tsx}` as the `render{:tsx}` prop on each `Field.Root{:tsx}`:

```tsx
<form.Field
  name="notifications"
  mode="array"
  children={(field) => {
    const isInvalid = field.state.meta.isTouched && !field.state.meta.isValid;
    return (
      <Field.Set>
        <Field.Legend variant="label">Notifications</Field.Legend>
        <Field.Group data-slot="checkbox-group">
          {options.map((option) => (
            <Field.Root
              key={option.id}
              orientation="horizontal"
              render={
                <Checkbox.Provider
                  isSelected={field.state.value.includes(option.id)}
                  onChange={(checked) => {
                    if (checked) {
                      field.pushValue(option.id);
                    } else {
                      const index = field.state.value.indexOf(option.id);
                      if (index > -1) field.removeValue(index);
                    }
                  }}
                />
              }
            >
              <Checkbox.Root>
                <Checkbox.Indicator />
              </Checkbox.Root>
              <Field.Label>{option.label}</Field.Label>
            </Field.Root>
          ))}
        </Field.Group>
        <Field.Error errors={isInvalid ? field.state.meta.errors : []} />
      </Field.Set>
    );
  }}
/>
```

## Submit Button State

Use `form.Subscribe{:tsx}` to disable the submit button while submitting or when the form is invalid:

<Alert.Root variant="warning">
  <AlertIcon variant="warning" className="size-4" />
  <Alert.Description>
    Always pass `selector` before `children` on `form.Subscribe`. Swapping the order causes TypeScript to lose inference on the selector's return type, resulting in type errors throughout the render function.
  </Alert.Description>
</Alert.Root>

```tsx
<form.Subscribe
  selector={(state) => [state.canSubmit, state.isSubmitting]}
  children={([canSubmit, isSubmitting]) => (
    <Button type="submit" isDisabled={!canSubmit}>
      {isSubmitting ? "Submitting..." : "Submit"}
    </Button>
  )}
/>
```

`canSubmit{:tsx}` is `false` when validation fails or a submission is already in flight. `isSubmitting{:tsx}` is `true` while `onSubmit` is pending.

## Resetting the Form

Use `form.reset()` to reset to default values:

```tsx
<Button type="button" variant="outline" onPress={() => form.reset()}>
  Reset
</Button>
```

## Array Fields

TanStack Form supports dynamic array fields with `mode="array"{:tsx}`:

<ComponentPreview name="tanstack-form-array-demo" />

```tsx
const formSchema = z.object({
  emails: z
    .array(z.object({ address: z.string().email() }))
    .min(1, "Add at least one email."),
});

<form.Field
  name="emails"
  mode="array"
  children={(field) => (
    <Field.Set>
      <Field.Legend variant="label">Email Addresses</Field.Legend>
      <Field.Group>
        {field.state.value.map((_, index) => (
          <form.Field
            key={index}
            name={`emails[${index}].address`}
            children={(subField) => {
              const isInvalid =
                subField.state.meta.isTouched && !subField.state.meta.isValid;
              return (
                <Field.Root
                  render={
                    <TextField
                      id={subField.name}
                      isInvalid={isInvalid}
                      name={subField.name}
                      onBlur={subField.handleBlur}
                      onChange={subField.handleChange}
                      type="email"
                      value={subField.state.value}
                    />
                  }
                >
                  <Input placeholder="name@example.com" />
                  <Field.Error errors={subField.state.meta.errors} />
                </Field.Root>
              );
            }}
          />
        ))}
      </Field.Group>
      <Button
        type="button"
        variant="outline"
        size="sm"
        onPress={() => field.pushValue({ address: "" })}
      >
        Add Email
      </Button>
    </Field.Set>
  )}
/>;
```

### Array Helpers

| Method                          | Description              |
| ------------------------------- | ------------------------ |
| `field.pushValue(item){:ts}`    | Add item to end of array |
| `field.removeValue(i){:ts}`     | Remove item at index     |
| `field.insertValue(i){:ts}`     | Insert item at index     |
| `field.swapValues(a,b){:ts}`    | Swap items at indices    |
| `field.moveValue(from,to){:ts}` | Move item to new index   |
| `field.replaceValue(i,item){:ts}` | Replace item at index  |
| `field.clearValues(){:ts}`      | Remove all items         |

## Linked Fields

When one field's validation depends on another (e.g. confirm password), use `onChangeListenTo{:tsx}` to re-run validation when the watched field changes:

<ComponentPreview name="tanstack-form-linked-fields-demo" />

```tsx
// [!code word:onChangeListenTo]
<form.Field
  children={(field) => ...}
  name="password"
/>
<form.Field
  children={(field) => ...}
  name="confirmPassword"
  validators={{
    onChangeListenTo: ["password"],
    onChange: ({ value, fieldApi }) => {
      if (value !== fieldApi.form.getFieldValue("password")) {
        return {
          message: "Passwords do not match.",
        };
      }
    },
  }}
/>
```
