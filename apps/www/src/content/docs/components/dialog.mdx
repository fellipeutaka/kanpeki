## Usage

### Single import

```tsx
import { Button } from "~/registry/ui/button";
import { Dialog } from "~/registry/ui/dialog";
```

```tsx
<Dialog.Root>
  <Button>Open</Button>

  <Dialog.Overlay>
    <Dialog.Modal>
      <Dialog.Content>
        <Dialog.Header>
          <Dialog.Title>Are you absolutely sure?</Dialog.Title>
          <Dialog.Description>
            This action cannot be undone. This will permanently delete your
            account and remove your data from our servers.
          </Dialog.Description>
        </Dialog.Header>
      </Dialog.Content>
    </Dialog.Modal>
  </Dialog.Overlay>
</Dialog.Root>
```

### Multiple imports

```tsx
import { Button } from "~/registry/ui/button";
import {
  DialogContent,
  DialogDescription,
  DialogHeader,
  DialogModal,
  DialogOverlay,
  DialogRoot,
  DialogTitle,
} from "~/registry/ui/dialog";
```

```tsx
<DialogRoot>
  <Button>Open</Button>

  <DialogOverlay>
    <DialogModal>
      <DialogContent>
        <DialogHeader>
          <DialogTitle>Are you absolutely sure?</DialogTitle>
          <DialogDescription>
            This action cannot be undone. This will permanently delete your
            account and remove your data from our servers.
          </DialogDescription>
        </DialogHeader>
      </DialogContent>
    </DialogModal>
  </DialogOverlay>
</DialogRoot>
```

### Alert Dialog

Use the `role="alertdialog"{:tsx}` prop on the `<Dialog.Content>{:tsx}` element to make an alert dialog.
Also, make sure to set the `isDismissable` prop to `false{:ts}` on the `<Dialog.Overlay>{:tsx}` or `<Dialog.Modal>{:tsx}`
to prevent the dialog from being dismissed by clicking outside of it.

<ComponentPreview name="alert-dialog-demo" />

### Sheet

Use the `side{:tsx}` prop on the `<Dialog.Modal>{:tsx}` element to make a sheet dialog.
