## Animation

The accordion uses the `--disclosure-panel-height{:css}` CSS variable to animate the height of the content area.

## Customization

If you need to customize the internal padding of the accordion content, you can use the `*:` Tailwind variant to target the content area directly.

```tsx
<Accordion.Content className="*:pb-12">
  Customized padding for the content area.
</Accordion.Content>
```
