## Usage

### Single import

```tsx
import { Collapsible } from "~/components/ui/collapsible";
```

```tsx
<Collapsible.Root>
  <Collapsible.Trigger>Is it accessible?</Collapsible.Trigger>
  <Collapsible.Content>
    Yes. It adheres to the WAI-ARIA design pattern.
  </Collapsible.Content>
</Collapsible.Root>
```

### Multiple imports

```tsx
import {
  CollapsibleContent,
  CollapsibleRoot,
  CollapsibleTrigger,
} from "~/components/ui/collapsible";
```

```tsx
<CollapsibleRoot>
  <CollapsibleTrigger>Is it accessible?</CollapsibleTrigger>
  <CollapsibleContent>
    Yes. It adheres to the WAI-ARIA design pattern.
  </CollapsibleContent>
</CollapsibleRoot>
```
