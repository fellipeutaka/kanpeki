## Trigger

You can use the `<Collapsible.Trigger />{:tsx}` component to create a button that toggles the visibility of the collapsible content,
or you can use the `<Button />{:tsx}` component as the trigger by passing it a `slot="trigger"{:tsx}` prop.

```tsx
<Collapsible.Root>
  {/* [!code highlight] */}
  <Button slot="trigger" variant="ghost">
    Is it accessible?
  </Button>
  <Collapsible.Content>
    Yes. It adheres to the WAI-ARIA design pattern.
  </Collapsible.Content>
</Collapsible.Root>
```

## Animation

The accordion uses the `--disclosure-panel-height{:css}` CSS variable to animate the height of the content area.
