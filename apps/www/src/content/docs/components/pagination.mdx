```tsx
import { Pagination } from "~/components/ui/pagination";

<Pagination.Root>
  <Pagination.Content>
    <Pagination.Item>
      <Pagination.Previous href="#" />
    </Pagination.Item>
    <Pagination.Item>
      <Pagination.Link href="#">1</Pagination.Link>
    </Pagination.Item>
    <Pagination.Item>
      <Pagination.Ellipsis />
    </Pagination.Item>

    </Pagination.Item>
  </Pagination.Content>
</Pagination.Root>;
```

</Tabs.Content>

<Tabs.Content id="multiple">

```tsx
import {
  PaginationRoot,
  PaginationContent,
  PaginationItem,
  PaginationLink,
  PaginationPrevious,
  PaginationNext,
  PaginationEllipsis,
} from "~/components/ui/pagination";

<PaginationRoot>
  <PaginationContent>
    <PaginationItem>
      <PaginationPrevious href="#" />
    </PaginationItem>
    <PaginationItem>
      <PaginationLink href="#">1</PaginationLink>
    </PaginationItem>
    <PaginationItem>
      <PaginationEllipsis />
    </PaginationItem>
    <PaginationItem>
      <PaginationNext href="#" />

  </PaginationContent>
</PaginationRoot>;
```

## Changelog

### 2025-02-13

- Wrapped `Pagination.Content` with React Aria [`Toolbar`](https://react-aria.adobe.com/Toolbar) for arrow key navigation between pagination items (single tab stop).
- `Pagination.Content` now accepts `ToolbarProps` from `react-aria-components` instead of `React.ComponentProps<"ul">`.
