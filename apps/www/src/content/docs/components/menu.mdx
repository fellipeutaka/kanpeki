## Anatomy

```tsx
import { Menu } from "~/components/ui/menu";

<Menu.Root>
  <Button variant="outline">Open</Button>

  <Popover.Content>
    <Menu.Content>
      <Menu.Item>Inbox</Menu.Item>
      <Menu.Item>Sent</Menu.Item>
      <Menu.Item>New Message</Menu.Item>
    </Menu.Content>
  </Popover.Content>
</Menu.Root>;
```
