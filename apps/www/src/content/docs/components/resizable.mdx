## Anatomy

```tsx
import { Resizable } from "~/components/ui/resizable";

<Resizable.Root orientation="horizontal">
  <Resizable.Panel />
  <Resizable.Separator />
  <Resizable.Panel />
</Resizable.Root>;
```

## Examples

### Vertical

Use the `orientation{:tsx}` prop to set the orientation of the resizable panels.

<ComponentPreview name="resizable-vertical-demo" />

```tsx
// [!code word:orientation]
<Resizable.Root orientation="vertical">
  <Resizable.Panel />
  <Resizable.Separator />
  <Resizable.Panel />
</Resizable.Root>
```

### Handle

Add `<Resizable.Handle>{:tsx}` inside `<Resizable.Separator>{:tsx}` to show a visible drag handle.

<ComponentPreview name="resizable-handle-demo" />

```tsx
// [!code word:Resizable.Handle]
<Resizable.Root>
  <Resizable.Panel />
  <Resizable.Separator>
    <Resizable.Handle />
  </Resizable.Separator>
  <Resizable.Panel />
</Resizable.Root>
```
