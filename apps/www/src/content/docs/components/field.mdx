### Structure

- `<Field.Root>{:tsx}` is the core wrapper for a single field.
- `<Field.Content>{:tsx}` is a flex column that groups label and description. Not required if you have no description.
- Wrap related fields with `<Field.Group>{:tsx}`, and use `<Field.Set>{:tsx}` with `<Field.Legend>{:tsx}` for semantic grouping.

### Without TextField

You can use `<Field.Root>{:tsx}` with `<Input>{:tsx}` directly, but you must provide `htmlFor{:tsx}` on the label and `id{:tsx}` on the input manually.

  <Input id="email" placeholder="Email" />
</Field.Root>

## Responsive Layout

- **Vertical fields:** Default orientation stacks label, control, and helper text—ideal for mobile-first layouts.
- **Horizontal fields:** Set `orientation="horizontal"{:tsx}` on `<Field.Root>{:tsx}` to align the label and control side-by-side. Pair with `<Field.Content>{:tsx}` to keep descriptions aligned.
- **Responsive fields:** Set `orientation="responsive"{:tsx}` for automatic column layouts inside container-aware parents.

## Validation and Errors

When using `<Field.Root>{:tsx}` with React Aria field components like `<TextField>{:tsx}`, `<NumberField>{:tsx}`, `<DateField>{:tsx}`, `<ColorField>{:tsx}`, or `<Select>{:tsx}`, pass `isInvalid{:tsx}` to the field component—it handles the invalid state automatically:

```tsx
<Field.Root render={<TextField isInvalid />}>
  <Field.Label>Email</Field.Label>
  <Input />
  <Field.Error>Enter a valid email address.</Field.Error>
</Field.Root>
```

If you're not using React Aria field components, you must handle validation state manually:

- Add `data-invalid{:tsx}` to `<Field.Root>{:tsx}` to switch the entire block into an error state.
- Add `aria-invalid{:tsx}` on the input itself for assistive technologies.
- Render `<Field.Error>{:tsx}` immediately after the control or inside `<Field.Content>{:tsx}` to keep error messages aligned with the field.

```tsx
<Field.Root data-invalid>
  <Field.Label>Email</Field.Label>
  <Input aria-invalid />
  <Field.Error>Enter a valid email address.</Field.Error>
</Field.Root>
```

## Accessibility

- `<Field.Set>{:tsx}` and `<Field.Legend>{:tsx}` keep related controls grouped for keyboard and assistive tech users.
- `<Field.Root>{:tsx}` outputs `role="group"{:tsx}` so nested controls inherit labeling from `<Field.Label>{:tsx}` and `<Field.Legend>{:tsx}` when combined.
- When using `<Field.Root>{:tsx}` with `render={<TextField />}{:tsx}`, React Aria automatically associates label, description, and error elements via `aria-labelledby{:tsx}` and `aria-describedby{:tsx}`.
