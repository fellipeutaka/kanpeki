We're excited to announce the initial release of Kanpeki, a component library featuring accessible and customizable React components built with [React Aria Components](https://react-spectrum.adobe.com/react-aria/components.html) and [Tailwind CSS](https://tailwindcss.com/).

## Key Features

- **Accessibility First** - Built on React Aria Components for WCAG compliance
- **Tailwind CSS 4** - Modern utility-first styling
- **CVA Variants** - Type-safe component variants with Class Variance Authority
- **Copy & Paste** - No npm install required, just copy the components you need
- **Customizable** - Full control over styling and behavior
