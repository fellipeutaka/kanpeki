## Pagination Component

Added documentation for the [Pagination](/docs/components/pagination) component, which provides page navigation with numbered links, previous/next controls, and ellipsis indicators.

<ComponentPreview name="pagination-demo" />

### Features

- Numbered page links with active state
- Previous and next navigation controls
- Ellipsis indicator for collapsed page ranges
- Accessible markup with `aria-label{:tsx}` and `aria-current="page"{:tsx}`
- Built on React Aria `<Link>{:tsx}` component
- Responsive — text labels hidden on small screens

Page number links only, without previous and next navigation.
