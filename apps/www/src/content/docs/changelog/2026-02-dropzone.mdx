## Dropzone Component

Added documentation for the [Dropzone](/docs/components/dropzone) component, an area into which files can be dragged and dropped.

<ComponentPreview name="dropzone-demo" />

### Features

- Drag-and-drop file uploads
- Customizable drop operation handling
- Disabled state support
- Composable with `<Dropzone.Provider>{:tsx}`, `<Dropzone.Root>{:tsx}`, and `<Dropzone.Label>{:tsx}`
- Built on React Aria `<DropZone>{:tsx}` component
