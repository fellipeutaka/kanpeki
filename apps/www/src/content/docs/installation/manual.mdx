## Add Tailwind CSS

Components are styled using Tailwind CSS. You need to install Tailwind CSS in your project.

[Follow the Tailwind CSS installation instructions to get started.](https://tailwindcss.com/docs/installation)

## Add dependencies

Add the following dependencies to your project:

```bash title="Terminal"
npm install cva@beta tailwind-merge tailwindcss-motion tailwindcss-react-aria-components -D
```

## Configure path aliases

I use the `~` alias. This is how I configure it in tsconfig.json:

```json title="tsconfig.json"
{
  "compilerOptions": {
    "paths": {// [!code highlight]
      "~/*": ["./src/*"]// [!code highlight]
    }// [!code highlight]
  }
}
```

The `~` alias is a preference. You can use other aliases if you want, like `@` or `#`.

**If you use a different alias such as `@`, you'll need to update import statements when adding components.**

## Configure Class Variance Authority

[Class Variance Authority (a.k.a. CVA)](https://beta.cva.style) is a utility that helps you manage class variance in your project.
Here's how I define it in `lib/cva.ts`:

```ts title="lib/cva.ts"
import { defineConfig } from "cva";
import { twMerge } from "tailwind-merge";

export const {
  cva,
  cx: cn,
  compose,
} = defineConfig({
  hooks: {
    onComplete: (className) => twMerge(className),
  },
});
```
